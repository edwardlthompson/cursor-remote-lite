# Tour (first run)

1. **PC:** install `CursorRemote.msi` / run tray EXE; confirm green status and Cloudflare/Pages URL in the relay log (`%USERPROFILE%\.cursor-remote-lite\relay.log`).
2. **Phone/tablet:** install `CursorRemote.apk` from [Releases](https://github.com/edwardlthompson/cursor-remote-lite/releases/latest), or let the tray ADB-pair.
3. **Pair:** scan QR / open deep link once; optional 2FA.
4. **Chat:** send a message; approve Run if asked.
5. **Dual pane:** in landscape, tap **Dual pane** between Chat and Screen — chat + editors/changes side-by-side; status strip for idle/running/waiting. Portrait: Dual pane is a full-screen side view.
6. **Open…** in Dual pane: open `BUILD_PLAN.md` or any file; editor tabs sync with Cursor.
7. **Screen:** live Cursor panel when you need raw UI.
8. Type `/coach` for the next BUILD_PLAN action.
